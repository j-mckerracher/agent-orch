# M6-04 Native Acceptance Checklist

Status: UNPROVEN; this task did not run native signed or clean-machine checks. Execute during the consolidated native pass (M7-32) against the exact recorded commit. Use clean snapshots/throwaway users and redact credentials from evidence. The N-1 and N artifacts must have different versions and sidecar bytes; a same-version rerun is not an upgrade. See [the detailed M6-04 runbook](m6-04-clean-machine-runbook.md) and [native lifecycle steps](m5-05-native-lifecycle-runbook.md#52-native-window-lifecycle-manual).

1. **macOS artifact and machine baseline.** Restore a clean supported macOS VM/user snapshot; record `sw_vers`, `uname -m`, app versions and artifact SHA-256 values. In each downloaded artifact directory run `shasum -a 256 -c SHA256SUMS`. **Expected:** hashes match and N-1/N are different versions. **Evidence:** `M6-04-macos-baseline.txt`.
2. **macOS signing and notarization.** On both `.app` bundles and daemon sidecars run `codesign --verify --deep --strict --verbose=2 <path>` and `codesign -dvv <path>`; run `spctl --assess --type execute --verbose=2 <app>` and `xcrun stapler validate <app>`. **Expected:** Developer ID authority, matching Team ID, hardened runtime, Gatekeeper accepted, stapled ticket valid. **Evidence:** `M6-04-macos-signing.txt`.
3. **macOS N-1 install and first launch.** Download N-1 through a browser, extract with Archive Utility, drag `Agent Orchestrator.app` to `/Applications`, then launch it. Record the window and `ps` output; inspect `~/.local/share/agent-orch`. **Expected:** no damaged/unidentified-developer block; connected UI; daemon runs from the installed bundle; `daemon.token`, `store.sqlite`, and `daemon.log` exist. **Evidence:** `M6-04-macos-n1-install.txt` and `M6-04-macos-n1-window.png`.
4. **macOS real-agent lifecycle.** Install/authenticate the supported test agent CLI, set a short isolated `AGENT_ORCH_DATA_DIR`, and use a test repository. In the installed UI register the repository, start a long task, record daemon/agent PIDs, close/reopen the window, then cancel the task. Kill only the daemon once more during a running task and relaunch. **Expected:** close/reopen preserves the running task and agent; cancel reaches `Cancelled` and the agent exits; recovery marks the interrupted task `Failed`, does not silently resume it, and leaves no orphan. **Evidence:** `M6-04-macos-lifecycle.txt` and `M6-04-macos-lifecycle.png`.
5. **macOS approvals.** In the N-1 installed UI create a pending review approval for a verified candidate; approve and deliver it, then repeat with a second candidate using reject and request-changes. **Expected:** approval remains pending until action; approved delivery creates `refs/heads/orchestrator/review/<task>` at exactly the candidate commit; reject/request-changes creates no ref and prevents approval/delivery. **Evidence:** `M6-04-macos-approvals.txt` and `M6-04-macos-approvals.png`.
6. **macOS idle N-1-to-N upgrade.** Quit the app, wait more than 60 seconds for the idle daemon to exit, replace the N-1 app in `/Applications` with signed N, and launch. **Expected:** prior project/task/approval data remains; the pending approval is still actionable; daemon logs show N-1 and N versions; N's daemon runs from the N bundle. **Evidence:** `M6-04-macos-upgrade-idle.txt`.
7. **macOS immediate upgrade.** Repeat the N-1-to-N replacement immediately after quitting while the old daemon is still running. **Expected:** the new app works without a mixed install; record whether it initially connects to the old daemon and verify the old daemon exits within about 60 seconds. **Evidence:** `M6-04-macos-upgrade-live-daemon.txt`.
8. **macOS signed installer smoke.** On a macOS release/build host with signed N-1 and N artifacts, run `node scripts/release/install-smoke.mjs macos --artifact-dir <N-dir> --old-artifact-dir <N-1-dir> --work <new-short-dir> --smoke-bin <target>/debug/examples/release_smoke --require-signed --out <evidence>/M6-04-macos-install-smoke.json`. **Expected:** no FAIL; `UPGRADE: <N-1> -> <N>`; structured `release_smoke` PASS for all 12 steps. **Evidence:** `M6-04-macos-install-smoke.json` and captured stdout.
9. **macOS uninstall.** Drag N to Trash. **Expected:** app is removed and `~/.local/share/agent-orch` is unchanged. **Evidence:** `M6-04-macos-uninstall.txt`.
10. **Windows artifact and machine baseline.** Restore a clean Windows 11 VM (and Windows 10 if supported), standard user, Defender/SmartScreen enabled, and record OS/build, WebView2 state, installer versions and SHA-256 values. Run `Get-FileHash -Algorithm SHA256 <installer>` and `Get-AuthenticodeSignature <installer>`; run `signtool verify /pa /all <installer>`. **Expected:** hashes match; both releases have different versions; signature is Valid with the expected publisher and timestamp. **Evidence:** `M6-04-windows-baseline.txt`.
11. **Windows N-1 install and first launch.** Download N-1 through Edge, run the per-user installer without elevation, then launch from Start. Record any SmartScreen prompt, installed file paths, signatures, WebView2 state and `%LOCALAPPDATA%\agent-orch`. **Expected:** no UAC prompt; app, daemon and uninstaller are installed; app/sidecar signatures are Valid; connected UI and daemon data files exist. **Evidence:** `M6-04-windows-n1-install.txt` and `M6-04-windows-n1-window.png`.
12. **Windows real-agent lifecycle and approvals.** Install/authenticate the supported test agent CLI, use a short isolated data directory and a repository with verified candidates, and in the installed UI start a long task, record daemon/agent PIDs, close/reopen the window, cancel the task, kill the daemon during a second task, then relaunch. Create two reviewable candidates: request approval and approve/deliver the first; reject and request changes on the second. **Expected:** the same agent/task survives close/reopen; cancellation reaches `Cancelled` and exits; recovery marks the interrupted task `Failed` without silent resume or orphans; the approved ref equals its candidate; reject/request-changes creates no ref and prevents delivery. **Evidence:** `M6-04-windows-lifecycle-approvals.txt` and `M6-04-windows-lifecycle.png`.
13. **Windows N-1-to-N upgrade.** With N-1 data and a pending approval, quit and install N over the same directory without uninstalling; verify again with the app still running. **Expected:** data and pending approval survive; N product version is installed; daemon logs show both versions; no mixed old/new files; record any request to close the app. **Evidence:** `M6-04-windows-upgrade-idle.txt` and `M6-04-windows-upgrade-running.txt`.
14. **Windows signed installer smoke.** On a native Windows release/build host run `node scripts/release/install-smoke.mjs windows --artifact-dir <N-dir> --old-artifact-dir <N-1-dir> --work <new-short-dir> --smoke-bin <target>/debug/examples/release_smoke.exe --require-signed --out <evidence>\M6-04-windows-install-smoke.json`. **Expected:** no FAIL; `UPGRADE: <N-1> -> <N>`; structured `release_smoke` PASS for all 12 steps; uninstaller leaves user data intact. **Evidence:** `M6-04-windows-install-smoke.json` and captured stdout.
15. **Windows uninstall.** Uninstall N from Settings > Apps and run the per-user uninstaller. **Expected:** app/install directory is removed, daemon stops or exits within about 60 seconds, and `%LOCALAPPDATA%\agent-orch` remains. **Evidence:** `M6-04-windows-uninstall.txt`.

Screen-reader and DPI checks are not specified by M6-04 and are not included in this checklist.
